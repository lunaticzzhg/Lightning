# Lightning Skills 索引

按任务选择相应 Skill；一项需求可先用需求工作流，再用设计或开发 Skill。只执行用户已要求的阶段。

| 任务 | Skill | 主要产物 |
| --- | --- | --- |
| 新想法、需求变更、PRD、交互原型、技术方案 | [quant-requirement-workflow](quant-requirement-workflow/SKILL.md) | 需求索引及对应文档 |
| Web 页面效果图、视觉方向、已认可设计的局部修改 | [quant-web-visual-design](quant-web-visual-design/SKILL.md) | 效果图与简短页面设计说明 |
| 实现或修改 Web、Python 功能 | [quant-feature-development](quant-feature-development/SKILL.md) | 代码、验证和测试报告 |
| 审视回测、交易、恢复等复杂业务链路 | [quant-flow-review](quant-flow-review/SKILL.md) | 基于证据的流程与问题结论 |
| 从需求单独设计或审查验收用例 | [quant-test-case-design](quant-test-case-design/SKILL.md) | 可执行、可观察的测试用例 |

产品事实以 `docs/product/`、`docs/architecture/` 和对应需求文档为准；Skill 只规定工作方法。小改动使用最轻的适用流程，不填与任务无关的检查表。
