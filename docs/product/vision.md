# 产品愿景（草案）

更新：2026-10-22 · 交付顺序见 [Roadmap](./roadmap.md)

面向小范围内部使用的 A 股、美股量化交易平台。覆盖数据与策略管理、回测、模拟和实盘；首期聚焦分钟级日内策略，未来评估高频方向。

## 核心能力

| 能力 | 使用者能做什么 |
| --- | --- |
| 数据管理 | 管理历史行情和运行所需行情，了解来源、覆盖范围、时效与质量 |
| 策略管理 | 使用开发者提交的策略代码版本，调整开放参数并保存配置 |
| 回测 | 使用历史数据检验策略，查看交易、成本和收益，复现结果 |
| 模拟 | 在虚拟账户运行策略，查看订单、成交和收益，不触发真实交易 |
| 实盘 | 连接个人券商账户运行策略，查看真实交易并完成对账 |
| 账户与账本 | 按环境记录资金、持仓及每笔变化的依据，核对账户和单次运行收益 |
| 风控 | 模拟与实盘下单前检查限制；异常时可暂停或停止运行 |
| 运行保障 | 发现数据停更、任务失败；中断后核对状态并安全恢复 |
| 运行与报表 | 每次运行查看交易、成本、持仓和收益变化；按日复盘收益与成本 |

## 产品原则

1. **结果可信：**每次运行可追溯策略、配置、数据、交易和成本；回测可复现，账本与报表可核对。
2. **交易安全：**回测、模拟、实盘严格隔离；实盘受风控约束，异常时能暂停或停止。
3. **过程透明：**运行中的订单、成交、资金和收益可查看；暂估收益与数据停更明确标示。
