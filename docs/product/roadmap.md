# 产品 Roadmap（草案）

更新：2026-10-23 · 依据：[产品愿景](./vision.md)。阶段按依赖顺序排列，不承诺日期。先在本机通过 Docker 和浏览器完成产品功能并逐阶段验收；完成后再决定是否部署到服务器。

| 阶段 | 交付结果 | 验收标准 |
| --- | --- | --- |
| 1. 本地平台与策略 | 在当前 Apple Silicon Mac 上用 Docker 启动管理台，通过本机浏览器管理策略代码版本及各版本的参数定义 | 无需域名或服务器即可使用；代码版本不可覆盖，重启后数据仍在，备份可隔离恢复 |
| 2. 历史数据 | 导入并管理首批分钟行情，查看来源、覆盖范围、质量和数据版本 | 异常数据可识别；修正生成新版本，已被引用的数据不被覆盖 |
| 3. 回测与报表 | 用指定代码版本、完整参数和数据运行回测；查看过程、逐笔交易、账户账本和每日收益成本 | 首个可用闭环：相同输入可复现，交易、账本与报表一致 |
| 4. 模拟交易 | 基于分钟行情持续运行虚拟账户，提供订单、风控、运行监控和恢复；沿用账本与日报表 | 不触发真实交易；交易与收益随事件更新，异常可见，恢复不重复下单 |
| 5. 本地运行保障 | 完善运行监控、操作记录、自动备份和恢复 | 故障可定位，关键操作可追溯；备份可恢复，异常运行不会悄悄继续 |
| 6. 实盘交易 | 连接个人券商账户，执行真实交易、风控、运行监控和日终对账；沿用账本与日报表 | 受控实盘可运行；异常可停止，平台与券商记录可对账，差异可定位和处理 |

高频方向在目标市场、接入条件和延迟指标明确后另定 Roadmap；当前阶段不预建高频引擎。

## 产品完成后再评估

是否部署到服务器、如何通过域名访问及如何支持多人协作，届时另立需求。本地实盘前仍须验证持续运行、断网恢复和交易安全；本机关闭时不能依赖它继续交易。
