# 产品 Roadmap（草案）

更新：2026-10-22 · 依据：[产品愿景](./vision.md)。阶段按依赖顺序排列，不承诺日期。

| 阶段 | 交付结果 | 验收标准 |
| --- | --- | --- |
| 1. macOS 平台与策略 | 本地管理台可安装、启动；管理策略代码版本和参数配置 | 新旧版本及配置可追溯；升级、重启和备份恢复后仍可使用 |
| 2. 历史数据 | 导入并管理首批分钟行情，查看来源、覆盖范围、质量和数据版本 | 异常数据可识别；修正生成新版本，已被引用的数据不被覆盖 |
| 3. 回测与报表 | 用指定策略、配置和数据运行回测；查看过程、逐笔交易、账户账本和每日收益成本 | 首个可用闭环：相同输入可复现，交易、账本与报表一致 |
| 4. 模拟交易 | 基于分钟行情持续运行虚拟账户，提供订单、风控、运行监控和恢复；沿用账本与日报表 | 不触发真实交易；交易与收益随事件更新，异常可见，恢复不重复下单 |
| 5. 服务器版 | 将平台、数据和运行记录迁移到服务器，提供认证、隔离与备份 | 迁移前后记录可核对，访问与恢复经过验证 |
| 6. 实盘交易 | 连接个人券商账户，执行真实交易、风控、运行监控和日终对账；沿用账本与日报表 | 受控实盘可运行；异常可停止，平台与券商记录可对账，差异可定位和处理 |

高频方向在目标市场、接入条件和延迟指标明确后另定 Roadmap；当前阶段不预建高频引擎。
