# 原型操作样本

打开[交互原型](../prototype.html)，先按股票、日期和周期查找。查找结果、交易日历及异常提示都是演示内容，不代表真实行情。

| 文件 | 用途 | 操作 |
| --- | --- | --- |
| [new-daily.csv](./new-daily.csv) | 补充 600519 的日线 | 从日线数据详情导入，确认成交量单位；成功后查看新版 K 线。 |
| [new-minutes.csv](./new-minutes.csv) | 补充 600519 的 1 分钟线 | 从分钟数据详情导入，文件时间选择“这一分钟的开始”。 |
| [correction.csv](./correction.csv) | 修改已有分钟的价格和成交量 | 从分钟数据详情导入，核对原值和新值后确认。 |
| [invalid.csv](./invalid.csv) | 演示无效价格和成交量 | 选择文件后会指出第 2 行错误，不生成版本。 |

新增来源时还需填写提供方和数据产品，确认价格处理方式。交易所无法可靠识别时才需选择。分钟线另需确认文件时间表示分钟开始还是结束；系统按文件中的时区偏移和市场换算时间。原型只模拟页面交互，刷新后上传结果会重置；正式支持的格式、交易日历和检查规则由技术方案及样本验证确定。
