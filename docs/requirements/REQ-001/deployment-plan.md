# REQ-001 便捷部署方案

- 状态：服务器部署已延期；本方案保留供产品在本机完成后评估，尚未实现或验证
- 目标：首次准备完成后，从本机执行一条命令，将确定的版本部署到测试服务器；失败时保留可恢复的旧版本与数据。

## 使用方式

```sh
./scripts/deploy-test
```

命令完成后输出版本、测试网址和检查结果。首次安装与以后升级使用同一入口；脚本根据服务器上的部署记录判断。正式环境以后沿用相同流程，但使用独立域名、凭证、数据库和备份位置，并单独授权发布。

升级期间会暂停写入，管理台会短暂不可用；安排在维护窗口执行。

## 首次准备一次

1. 在服务器安装 Docker Engine 与 Compose，设置 SSH 密钥登录，开放域名入口所需的 80/443 端口；域名解析到服务器。
2. 配好私有镜像仓库。本机有推送权限，服务器只有拉取权限。测试环境可选阿里云 ACR 个人版，但须先确认账号和地域可用；个人版仅适合开发测试，正式环境改用有服务保障的仓库。
3. 在服务器生成测试环境的数据库密码和访问凭证，填写私有 `.env`；准备服务器外的受控备份位置。凭证和备份不进入 Git 或镜像。
4. 检查固定容器网段、可用内存与磁盘。目标机为 2 vCPU、2 GiB、40 GiB，隔离恢复会额外启动数据库，实际资源是否够用须在目标机演练。

这些需要云控制台、DNS 和凭证的步骤不能由发布命令凭空完成。提供一次性初始化检查，列出缺项；准备好后，日常发布只用上述命令。

## 一条命令做什么

| 顺序 | 动作 | 不通过时 |
| --- | --- | --- |
| 1. 发布前检查 | 检查 Git 提交、目标配置、SSH、镜像仓库、备份位置和服务器空间；不允许用未提交代码冒充某次发布。 | 停止，不改服务器。 |
| 2. 构建与传输 | 在本机或构建机用同一 `deploy/Dockerfile` 构建 `linux/amd64` 镜像；用 Git 提交号标记，推送私有仓库，并记录镜像摘要。将本次 Compose 配置和部署工具作为带版本的部署包传到服务器；不传 `.env`、密钥或本地数据。 | 保留当前服务。 |
| 3. 首次安装或升级 | 首次安装运行迁移并启动 MySQL、应用和 Caddy。升级则调用现有 `scripts/deploy_data.py`：停写、备份、隔离恢复和迁移核对，通过后再更新现用库与应用。 | 升级按备份恢复旧数据和旧镜像；自动恢复失败则保持应用停止并提示人工处理。 |
| 4. 验收与记录 | 经测试域名检查 HTTPS、未授权访问被拒绝、授权后 `/api/status` 可用；记录提交号、镜像摘要、部署时间和备份文件。全部通过后才标记新版本为当前版本。 | 尚未完成发布；按旧部署包和备份回退。 |

镜像使用摘要锁定，避免同名标签被覆盖后拉到不同内容。部署包保留上一版，环境配置与部署包分开保存；切换失败时使用上一版配置。前端已经包含在应用镜像中，与后端同版发布，服务器无须安装 Node。

## 对现有实现的改动

- 新增 `scripts/deploy-test` 作为本机发布入口，以及一次性初始化检查；复用 `deploy/test/compose.yaml`、`deploy/Dockerfile` 和 `scripts/deploy_data.py`，不另建发布服务。
- 调整升级脚本：支持部署包与私有配置分开保存；将**域名入口检查**纳入成功条件，在写入新镜像为当前版本之前完成；失败时连同旧部署配置一起恢复。现有脚本依赖固定目录，只检查应用和数据库，不能把它当成完整的一键发布。
- 将发布记录和部署包留在服务器受控目录，备份保存在服务器外。脚本须防止同时发布，并避免日志输出凭证。
- 更新[运行手册](./runbook.md)，记录首次准备、发布、故障定位和人工回退。首次在目标机验证安装、实际跨版本升级、域名检查、隔离恢复耗时和失败回退后，才将本方案标为已落地。

选择 Docker Compose 是因为当前只有一台服务器，现有服务已经按 Compose 组织；[Docker 官方文档](https://docs.docker.com/compose/how-tos/production/)也支持单机发布。Apple Silicon 本机向服务器构建 `linux/amd64` 镜像按 [Docker 多平台构建说明](https://docs.docker.com/build/building/multi-platform/)处理。[阿里云 ACR 个人版说明](https://help.aliyun.com/zh/acr/user-guide/create-a-container-registry-personal-edition-instance/)限定其用于开发测试，地域可用性以控制台为准。
